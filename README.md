# Leif Pedersen — Professional Biography Website

A responsive, static personal biography site for Leif Pedersen, built with HTML, CSS and vanilla JavaScript.

## Local preview

Open `index.html` directly in a modern web browser, or use a lightweight local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — site structure and biography content
- `styles.css` — visual system, responsive layouts and animations
- `script.js` — small client-side enhancements
- `Leif_Avatar.jpg` — upload the supplied avatar image to the repository root to populate the hero image

## Deploying

This is a static site and can be deployed through GitHub Pages, Vercel, Netlify, or any standard web host.

## Content notes

The site uses a third-person professional biography focused on technology enablement, cloud, AI, engineering capability, partner ecosystems and technology community involvement. Review professional claims and career dates before publishing publicly.
